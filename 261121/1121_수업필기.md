# 1121_수업필기

**IMU**: Inertial Measurement Unit, 관성 측정 장비
Gyroscope, Accelerometer(가속도), Magnetometer(자기장)


## 임베디드 통신 프로토콜
IMU -> MCU, MCU <-> MCU

- **동기:** 통신할 대상과 주기(clock)를 일치시켜 데이터를 송수신
- **비동기:** 주기 없이 약속한 전송 속도와 프레임 형식을 사용해서 데이터 송수신

- TX: transmit, 통신할 RX와 연결하여 데이터 전송
- RX: Receive, 통신할 TX와 연결하여 데이터 받음

종류
- **UART**: 비동기 직렬. TX: transmit <-> RX: Receive 데이터선 2개 서로 연결하여 송수신
 Start bit 전송(pull up 저항에서 pull down)    ->     Data bit 전송 (8bit, LSB 부터)     ->   Stop bit 전송
  
- **I^2C**:   동기 직렬. SDA(Serial Data, 데이터 선 1개), SCL(Serial Clock)
시작할 땐 Pullup->pulldown. 클락이 올라가는 순간마다 데이터를 읽음.  받는 쪽이 8bit 마다 ACK/NACK 신호 전송
